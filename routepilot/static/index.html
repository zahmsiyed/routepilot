      How to use RoutePilot

      Allow the downloaded Mac launcher

      Unzip the Mac download so the RoutePilot folder is inside Downloads. Open Terminal and paste:

      xattr -dr com.apple.quarantine ~/Downloads/RoutePilot
chmod +x ~/Downloads/RoutePilot/"Launch RoutePilot.command"

      These commands remove the folder’s download quarantine flag and make the launcher executable. Adjust the path if needed, then double-click Launch RoutePilot.command.

      Choose Stationary for one location, Running for pedestrian paths, or Driving for roads. Routes calculate automatically when you add, move, or remove checkpoints.

      Click the map to add a numbered checkpoint, drag it to move it, or click the marker to remove it immediately. Remove also works from the list. Undo restores your last edit; ⌘Z works outside text fields.

      Search for a place or address above the map and press Enter or Search. Select a match to preview it, then choose Add checkpoint or Use this location. Searching does not change the iPhone’s location. Include a city for more specific results. Search text is sent to Photon only when submitted.

      Metric / Imperial changes speed, distance, and variation units. The underlying route and speed stay the same. Vary speed chooses smooth changes inside your ± range, bounded to 0.1–250 km/h. Lateral drift adds a smooth side-to-side offset of at most 2 m (6.6 ft), fading out at route corners and endpoints. Both options are off by default and apply only while moving.

      Adjust speed, then press Start. Pause holds the current position. The endpoint stays applied until you press Restore real location.

      Keep the Mac running and USB connected. Closing this tab does not stop an active simulation. If the phone disconnects, reconnect and Restore. If that fails, restart the iPhone.

      Routing needs internet access and sends checkpoints to FOSSGIS. If routing fails, move a checkpoint or retry; playback does not fall back to a straight line. More options contains coordinates, looping, and GPX tools. GPX exports use the base speed and route, without random variations.

      Individual iPhone apps may detect or ignore simulated locations. Speed controls coordinate timing; apps may report it differently.
